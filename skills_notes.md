### Notes
Skills can be summed into two types:
- Reference content
- - These skills are more about context on the codebase / feature we are working through. This could be a verbiage extractor / design where we identify multi-used hard-coded strings and include them in our common language file and make updates, then adhere to putting multi-used strings into the verbiage file for future use when creating new features.
- Task content
- - These skills should be used for tasks like: unit-test skills, where this skill would have tasks to run the test, check for failures, update failures to adhere to changes, run tests again, repeat till finished.
